# 公众无障碍证据记录 · 方法模式（脱敏版）

> 本文档仅保留**可公开的产品方法学**，不含任何个人身份信息、平台账号、具体地址或可识别个案。
> 用途：指导 BarrierLens 的文案、导出模板与 Demo 叙事，**不得**作为对特定创作者或账号的引用或背书。

## 1. 适用边界

BarrierLens 聚焦：**盲道占用、无障碍入口受阻、通行链断点**。

不扩展为泛城市治理话题（非机动车道、井盖、电梯等），避免产品定位发散。

## 2. 公众记录的有效结构（抽象模板）

典型「发现 → 说明 → 诉求」四段式，可用于 AI 输出与导出模板：

| 环节 | 内容要点 | BarrierLens 对应字段 |
|------|----------|----------------------|
| 现象 | 什么被挡、挡在哪里 | `obstacles`, `blockedPath`, `sceneDescription` |
| 影响 | 谁过不去、风险多大 | `affectedGroups`, `riskLevel`, `pathStatus` |
| 依据 | 与无障碍通行相关的规范或管理要求（概括表述，非法律意见） | `managementAction`, `suggestion` |
| 动作 | 建议责任方与可执行整改 | `responsibleParty`, `suggestedActions` |

语气：**陈述事实、描述影响、提出可跟进建议**；不做人身攻击、不煽动对立。

## 3. 与政务/物业沟通的合规口径

导出与 UI 提示应明确：

- 工具**不**代用户投诉、**不**代用户执法、**不**构成专业验收或法律责任认定。
- 记录需**人工复核**；AI 输出为辅助整理，非最终结论。
- 影像与地点由用户自行决定是否分享；**默认仅存本机**（localStorage）。
- 对外传播时：避免可识别路人面部、车牌；地点宜概括（如「某地铁口」「某商场北门」），避免精确门牌。
- 如需向管理部门反映：使用当地公开的政务服务渠道（如 12345 等），按官方要求提交材料。

## 4. Demo / Hero 叙事建议（15–30 秒）

1. 第一人称视角：盲道或入口被占用（使用**自有或已授权**素材，无第三方水印/贴纸）。
2. 打开 BarrierLens → 拍照或选样例。
3. 展示结构化诊断卡片（问题类型、风险、建议动作）。
4. 归档至本机时间线 → 导出 Markdown 摘要。

旁白方向：**「看见之后，留下可跟进的证据」**，而非模仿任何具体账号话术或标签。

## 5. 刻意不写入代码库的内容

以下信息**不得**进入仓库、文档或 UI：

- 第三方创作者真实姓名、雇主、收入等个人信息
- 社交平台账号 ID、粉丝数、作品列表、评论原文
- 未脱敏的具体路名、门牌、商户名
- 未经授权的他人影像、水印视频、平台 UI 截图
- 对特定个人的比较、排名或「对标某某账号」类营销表述
