# BarrierLens Demo 视频脚本（冲第一名口径版）

目标时长：3:40 - 4:20  
提交限制：严格小于 5 分钟  
核心打法：先讲真实社会痛点，再证明 Gemma 4 不只是识图，而是在生成可归档、可复查、可撤回的无障碍反馈证据链。

## 一句话定位

BarrierLens 不是自动执法系统，而是一个让普通人把“这里过不去”转成可提交、可归档、可复查证据的 Gemma 4 无障碍反馈工具。

## 必须出现的画面证据

1. 真实现场图片，不要只用 UI 截图。
2. `/api/analyze` 或结果页 banner 显示：
   - `analysisSource=gemma`
   - `mockMode=false`
   - `modelName=gemma-4-26b-a4b-it`
3. 结构化结果字段：
   - 问题类型
   - 风险等级
   - 影响人群
   - 现场摘要
   - 整改建议
4. 本机档案 / 时间线。
5. 导出报告。
6. 反馈闭环图。
7. 隐私边界说明。

## 评委第一眼要听到的三句话

1. 很多无障碍问题不是没人看见，而是看见之后很难形成可跟进证据。
2. Gemma 4 的作用不是复述照片，而是把现场照片转成结构化反馈和整改语言。
3. BarrierLens 从记录、归档、公开、复核到整改复拍，形成了一个轻量但完整的反馈闭环。

## 避免的说法

- 不说“我们做了一个识别盲道占用的 AI 小工具”。
- 不说“自动判断责任方并提交投诉”。
- 不说“替代监管部门处理无障碍问题”。
- 不在正式提交视频里展示 `mock` 或 `mock_fallback`，除非明确口播“这是演示降级，不代表真实模型能力”。
